# 绿电实验室 · 本地 n8n

本机已部署固定版本 n8n 2.43.8，导入并发布 **绿电实验室 · 数据接收与负载初判**。

## 启动与查看

双击 **启动本地n8n.command**，保持该窗口运行，然后打开 [本地 n8n](http://localhost:5678)。脚本发现已有服务时不会重复启动。首次管理界面需要的账户和密码请本人设置；自动接收端已通过测试。

只监听本机 127.0.0.1，不向校园网络或互联网开放。电脑休眠或关机时不持续采集。应用连接插座 Wi-Fi 不影响本机 n8n 通信；没有互联网时 Drive 会等待恢复网络。

## 连接 Mac 采集器

在 **绿电实验室 Mac 1.2** 选择“加载配置”，打开本目录 **runtime-data/Mac本地n8n配置.json**。核对插座地址 192.168.1.2:8266、保持标定未勾选，再连接。配置含本机私有接收路径，请勿分享或上传。

未标定摘要只包含 ADC 及空的功率、电量；接收结果为待标定，不能据此证明开或关。完成参考仪表标定和阈值验证后，沿用采集器带保持时间的负载状态，不在 n8n 重新套一个瞬时开关阈值。

本流程拒绝无效时间、缺少来源、未标定却带瓦数等记录。记录距接收时间超过 15 秒时显示未知/历史；测试来源明确标注非实物。没有继电器控制和邮件动作。当前不做 Webhook 失败补发或业务去重；执行记录可重复，原始持久化以采集器本地文件及 Drive 备份为准。

## 文件与迁移

- **绿电实验室-接收流程-模板.json**：不含私有接收路径，可导入其他 n8n；导入后先设置自己的随机接收路径并发布。
- **normalize-summary.cjs**、**test-receiver.cjs**：接收校验及 12 项规则检查。
- **n8n接收验证.json**：4 项本地 HTTP 测试结果，均为明确标注的模拟记录。
- **runtime-data/**：本机 n8n 数据库、登录和加密配置、私有接收路径。不要公开、不要与软件模板一起上传。保留目录才能继续使用当前实例。
- **package.json / pnpm-lock.yaml / pnpm-workspace.yaml**：固定依赖及构建许可。运行环境是本机 Node 24.19.0，启动脚本使用明确路径。

停止后可运行同一脚本重新启动。若更换电脑，使用支持的 Node 版本及固定锁文件恢复依赖，再自行初始化 n8n 账户；不要把本机认证文件作为公开安装包。

此部署用于当前电脑的实验室验证。它不自动同步旧网站、不训练模型、不代替实际电表标定。软件模板和采集数据可分别备份；不要把 node_modules 或 runtime-data 放进采集数据目录。
