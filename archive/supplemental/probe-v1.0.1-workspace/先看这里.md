# 插座 IP 读取测试器

这是独立的 Mac 测试软件。目标是确认 `192.168.1.1:8266` 能否连接、是否确实返回字节。先用它完成实物测试，再决定怎样接入绿电实验室。

双击同目录的 **插座IP读取测试器.app**。无需 Windows、Python 或互联网。此程序有独立应用名称和标识，不会与绿电实验室的多个副本混淆。

## 你离线时按这个顺序操作

### 这次报告后的下一步

2026-10-19 22:44 的报告确认：电脑当时为 `192.168.1.101/24`，连接 `192.168.1.1:8266` 超时、接收 0 字节。提供的 YS8000 手册明确写了初始设备地址 **192.168.1.2:8266**（热点模式、服务器角色）。下一次在插座热点下，先将 IP 改为 **192.168.1.2** 再测试。软件启动默认值仍保留之前指定的 `.1`，重开窗口时请核对地址。

如果 `.2` 能建立 TCP 但没有返回字节，并确认设备采用此手册协议，再选择下文的 `ifconfig` 查询和短时采集。先找到实际接受 TCP 的服务地址，再核对波形协议。

### 1. 先做只连接测试

1. 给插座通电，由你手动将 Mac 连接到插座实际 Wi-Fi 热点。
2. 打开测试器，保留 IP **192.168.1.1**、TCP 端口 **8266**。若提供方确认设备使用其他地址，以真实配置为准。
3. 模式选 **只连接，等待设备主动返回**，点击 **开始本次测试**。
4. 最多等 8 秒连接；连接成功后，再等待 5 秒接收。无论成功、失败还是零字节，都会自动保存报告。

| 结果 | 含义 |
| --- | --- |
| TCP 未建立连接 | 先核对插座热点、IP/端口、系统本地网络权限；尚未进入设备报文读取 |
| TCP 已连接，本次未收到任何字节 | 网络连接已发生，设备可能需要查询或采集命令 |
| 收到 N 字节原始数据 | 这个地址确实返回了内容；暂时不等于电压、电流已经解析正确 |

软件不会自动切换 Wi-Fi。系统如询问本地网络权限，请由你确认是否允许此工具访问要测试的插座。

### 2. TCP 已连但无数据，再按设备手册查询

仅在提供方确认设备使用此前提供的 **YS8000 手册协议**时：

1. 将模式选为 **YS8000：查询配置 ifconfig**。
2. 勾选确认设备协议，然后点击 **开始本次测试**。
3. 工具重新连接，发送一次 `ifconfig`（不附加回车），接收约 3 秒后保存回复。

### 3. 再读一段原始数据

1. 选 **YS8000：读取原始数据 # / $**，保留协议确认勾选。
2. 点击开始。工具重新连接，发送 `#`，接收约 3 秒，然后尝试发送 `$` 停止本次采集。
3. 不需要先填写帧头、帧尾、采样率或系数。HEX 区显示收到的实际字节。
4. 点 **打开结果目录** 查看文件。重新连接平时的网络后，把这一次的结果带回来。

发送成功表示数据已发往 TCP 连接，不证明设备执行了命令；报告会分别记录是否发出开始和停止指令。设备不使用 YS8000 时，不应猜用这组命令。

## 自动保存了什么

默认在应用旁的 **测试结果** 文件夹中，每次测试建立单独的时间与编号目录：

- **测试结果.txt**：人可读结论及下一步。
- **诊断报告.json**：地址、端口、连接与接收字节数、错误、命令发送情况、测试来源等。
- 1.0.1 版还记录测试开始和结束时的本机 IPv4、子网掩码及可读到的连接路径；不会获取 Wi-Fi 密码或自动更改网络。
- **原始接收.bin**：本次接收的原始字节，保持不变；零字节测试也保存空文件作为记录。
- **通信日志.txt**：连接、请求和结束日志。
- **原始数据预览.txt**：前 1024 字节的十六进制预览。
- 查询模式若返回 UTF-8 文本，还保存隐藏常见密码字段后的文本副本。

原始 BIN 可能包含设备网络配置等内容，分享前请留意。软件不上传文件、不调用绿电实验室接口。原始缓存最多 2 MiB，达到上限会结束读取。

若保存位置不可写，窗口会显示错误并保留本次内存数据；先点 **更换保存位置** 重新保存，再开始下一次测试。没有保存成功时，软件会阻止直接开始下一轮。

## 如何确认可以接入绿电实验室

需要一次**真实插座地址的原始收数结果**。本机回环地址 `127.x.x.x` 的测试会醒目标注为本机自测，不能证明实物读取成功。设备身份、命令协议、采样率、点数、字节序和换算系数，需要依据真实报文与提供方资料再核对。

本工具不计算电压、电流，不训练识别模型，不把未确认的字节包装成测量数据。通过实物收数后，再将确认的通信程序接入绿电实验室。

## 运行与源码

最低编译目标 macOS 13，包含 Apple Silicon 与 Intel 两种架构。当前 Apple Silicon Mac 实际运行验证；Intel 未实机测试。本工具为本机临时签名，未取得 Apple 开发者公证，不需要关闭 macOS 安全保护。

`Source/` 是完整新源码；`Tests/` 是仅使用本机回环地址的测试服务器与原生测试；`build.sh` 可在装有 Xcode Command Line Tools 的 Mac 上重建应用。运行测试器本身不依赖这些开发工具。
