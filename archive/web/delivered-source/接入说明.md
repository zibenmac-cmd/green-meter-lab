# 智能电表接入说明

网站：[打开绿电实验室](https://green-meter-lab-ahaoxiao.ziben-mac.chatgpt.site)（私有访问，需要登录）。

## 先使用网页

初次打开默认展示模拟数据，帮助说明比赛流程。点击「真实数据」查看数据库；未接入设备时显示「未连接」。演示数据不会保存为实测记录。

可先从「数据管理」下载空白 CSV 模板，将电表实际导出的记录整理后导入。表头为：

```csv
device_id,timestamp,power_w,energy_kwh
```

设备编号使用 `meter-01`；时间格式例如 `2026-10-05T12:00:00+08:00`；功率使用 W，电量为电表累计 kWh，不能填当天用电量。历史导入不会让电表显示在线。导入最多 4 MB、20,000 条；相同设备、相同时间不重复保存，已有值优先。比赛正式结果应使用真实数据。

## 选择电表时需要确认

本项目尚未采购硬件。采购前请向设备供应商确认：可否读取瞬时功率（W）与累计电量（kWh）、能否每 10–60 秒获取一次数据、有没有公开可用的本地或云端接口，以及获取数据是否需要订阅或专有网关。具体型号与协议确认后，再实现设备读取部分。网页接收接口不等于任何品牌电表都能直接连接。

## 自动采集流程

真实电表 → 型号对应的读取程序 → 标准 JSON 记录 → 本项目接收接口 → 数据库 → 网页每 10 秒刷新。

1. 登录私有网页，在「设备配置」设置电器名称、阈值、电价和碳排系数。
2. 点击「生成采集密钥」，安全保存一次性显示的密钥。轮换后旧密钥立即失效。
3. 为适配程序取得这个私有 Site 的平台服务访问凭据。支持的凭据由 Sites 的 `get_site` 返回 `siwc_bypass_bearer_token`，或通过原生 Sites 服务访问工具取得；硬件准备好后可让 Codex 帮助读取此网站的接入凭据。不要把站点改成公开来绕过私有访问。
4. 在适配程序的运行环境安全设置变量：`METER_SITE_URL`（网站根地址）、`METER_INGEST_KEY`（网页生成的密钥）、`METER_SITE_ACCESS_TOKEN`（平台服务访问凭据）。不要将它们写入源代码、截图、CSV 或比赛 PPT。
5. 将真实设备读取结果转换为下列 JSON 格式。设备采样时间应准确，建议每 10–60 秒发送一次。

```json
{
  "device_id": "meter-01",
  "timestamp": "2026-10-05T12:00:00+08:00",
  "power_w": 760,
  "energy_kwh": 125.32
}
```

上面的数字仅为格式示例，不能作为实测数据提交。

`POST /api/ingest` 所需请求头：

```
Content-Type: application/json
Authorization: Bearer <采集密钥>
OAI-Sites-Authorization: Bearer <该网站的平台服务访问凭据>
```

成功返回 `{"inserted":1,"duplicates":0}`；重复提交返回插入 0、重复 1。采集接口接受单条或 `{"readings":[...]}`；密钥校验失败返回 401，字段无效返回 400。单次最多 4 MB 或 20,000 条。软件在本地完成了这些接口验证；发布后的设备接入仍需用实际电表进行验证。

## 附带的发送适配程序

`adapters/send_readings.py` 使用 Python 标准库，无需安装额外包。它从标准输入逐行读取已由真实电表读取程序产生的 JSON，并发送到网站。它不读取特定型号的电表，也不生成模拟数据。

安全配置好上述三个环境变量后：

```sh
python3 adapters/send_readings.py < real-meter-readings.jsonl
```

实时读取程序也可将每条 JSON 通过管道传入。设备读取部分需要等型号确定后编写。服务错误或网络错误最多重试 5 次，相同采集时间可安全重试；认证或字段错误会停止，要求修正配置。私有站点若返回登录页面，需核查平台服务访问凭据。

## 比赛演示顺序

1. 展示项目目标：记录、分析、实施节电措施、对比效果。
2. 演示实时电表：真实模式下说明设备状态、当前功率与累计读数。
3. 打开用电统计：展示日用电趋势、峰值及数据覆盖时长。
4. 实施措施前后各记录至少一个有效日，再在「节电分析」选择两个独立时段。短时间现场演示可展示功率变化，不能据此声称已证明每日节电效果。
5. 展示异常提示及 CSV / 分析报告导出，说明数据来源与计算口径。

## 如何解读结果

所有日期按 UTC+8。功率是瞬时读数；累计电量是电表总读数；时段用电量由累计差值计算。读数降低标记重置，该段不计作节电。跨日间隔电量按时长均摊，因此每日结果为估算。

“有效日”表示连续采样间隔 ≤60 秒的覆盖时长合计 ≥20 小时且无重置（日期必须已结束）。节电对比使用有效日的日均值，显示有效日与有记录日数量；数据不足会提示无法计算。使用时长、负载、天气也会影响用电，观察性对比不能单独证明措施的因果效果。

碳排系数默认 0.785 kg CO₂/kWh，来自计划图片，未作为本地区权威系数核实；默认电价 0.6 元/kWh，请改成实际参数。相关碳排、电费结果均标为估算。

未实现邮件报警、远程断电和积分兑换。电表选型和真实硬件连接尚待完成。

## YS8000 设备接入

本版已增加专用接收接口 `/api/ys8000`、6400 Hz 采集程序、波形分析、KNN 候选识别和短时功率预测。设备未到位时不显示在线。完整流程见 [YS8000 接入指南](public/hardware/YS8000接入指南.md)。

网关电量为有功功率积分估算，与普通接口接收的硬件累计电量读数分开标记。原压缩包缺少模型权重，当前 KNN 可使用新标注片段训练，研究演示稿中的 BiTCN 剩余时间预测仍待模型与特征流水线。
