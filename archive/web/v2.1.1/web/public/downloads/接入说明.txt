绿电实验室 Web 2.1.1 · 使用已有 Mac 软件接入

1. 使用绿电实验室 Mac 1.6 或更新版本，无需另装 Python 采集器。
2. 网站切换「真实记录」并使用管理员口令登录，在「记录与接入」生成采集密钥。已有密钥可以继续使用；更新会使旧密钥失效。
3. 打开 Mac 软件「网站同步」，填入网站登记的设备编号和采集密钥，勾选开启后保存。采集密钥是 gml_ 开头的上传凭证，不是管理员登录口令；密钥保存在 Mac 钥匙串。
4. 插座通电后，Mac 手动连接插座热点，软件以 TCP 主动连接 192.168.1.2:8266。供电与采样指令仍由用户手动操作。
5. 保持软件运行，可以最小化。插座热点无互联网时先在本机保存，恢复联网后自动补传；实时上传需同时连通插座和互联网，例如 Wi-Fi 连插座、网线连互联网。退出或睡眠不会继续采集。
6. 网页负责查看与分析，不能直接代替 Mac 软件建立该插座的原始 TCP 连接。原始高频 BIN 在 Mac 保存并沿用 Google Drive 备份，云端接收功率摘要与识别窗口。
7. 参考系数尚未实物标定，功率、电量与费用均为估算；6400 Hz 是配置值。负功率不会取绝对值冒充耗电，断连与会话变化不补算。演示、回放和回环测试不会上传到真实空间。
8. 电器识别仍需真实分状态样本、训练及验证；仅绑定采集密钥不会自动学会电器。
