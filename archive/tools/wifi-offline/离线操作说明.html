插座 Wi-Fi 离线连接说明

先连接热点、确认 TCP 可达，再查询信息。全程暂不连接洗衣机或其他电器。

开始前

保持校园网，准备好说明和工具

  • 保存本文件和同目录的 device_probe.py。本页不需要互联网，也不依赖线上绿电实验室。
  • 这台 Mac 已确认有 /usr/bin/nc 和 /usr/bin/python3，无需联网安装软件。
  • 从提供方确认设备热点名称、密码，以及实际 IP/端口。照片没有型号铭牌，外形本身不能证明它使用 YS8000 协议。
  • 你提供的 YS8000 1.1 手册默认 IP 为 192.168.1.2、TCP 端口 8266，热点/服务器模式。旧代码的地址为 192.168.1.1，因此以下默认地址只是手册候选值，实际配置优先。

本次先做网络通信验证，不控制继电器、不修改设备配置。不要为了找热点按复位键：手册说明短按会初始化配置，长按会重启。

01

给插座通电，找到正确热点

  1. 由你给插座供电，插座输出端暂不接电器。
  2. 打开 Mac「系统设置 → Wi-Fi」，观察通电前后出现的网络名称。
  3. 按提供方的说明确认哪一个是设备热点，输入对应密码连接；不要尝试猜测附近网络的密码。
  4. 看到设备热点显示「已连接」后，再继续下一步。

设备热点可能没有互联网。出现“无互联网连接”不等于 Wi-Fi 没连上；当前聊天和线上网页可能暂时无法继续加载，照着本页离线操作即可。

02

记录 Mac 的局域网信息

在设备热点右侧点「详细信息… → TCP/IP」，记录或截图：Mac IP 地址、子网掩码和路由器地址。保持现有 DHCP 配置。

若 IP 是 169.254.x.x，或一直拿不到地址，先记录结果并向提供方确认网络配置；不要直接猜测静态 IP。路由器地址也不一定就是设备 TCP 服务器地址。

03

先检查 TCP 端口，不发送控制命令

按 ⌘ 空格，输入「终端」并打开。只有在实际设备地址与手册一致时，复制以下命令：

/usr/bin/nc -n -vz -G 3 192.168.1.2 8266

若实际 IP/端口不同，请替换对应数字。这条命令只尝试连接指定端口，不修改 Wi-Fi 或设备设置。

输出含义与下一步
succeeded该地址的 TCP 端口可连接，尚未证明它返回的是有效测量数据。
Connection refused收到连接拒绝；核对端口和设备服务是否已启动。
timed out／No route to host未建立连接；核对当前 Wi-Fi、Mac IP、设备地址和网络条件。保留截图，切回校园网后一起检查。
04

用离线工具保存检查结果

终端先输入 cd （末尾有空格），把这个工具文件夹从 Finder 拖入终端，再按回车。随后输入：

/usr/bin/python3 device_probe.py --host 192.168.1.2 --port 8266

默认只检查 TCP 连接，结果保存在工具目录下的「读取结果」文件夹中。实际地址不同需替换。

以下两项只在提供方确认这只插座使用你提供的 YS8000 协议之后执行。型号未确认时，到 TCP 检查这一步即可。

查询设备配置

/usr/bin/python3 device_probe.py --host 192.168.1.2 --port 8266 --ys8000 --config

发送一条小写 ifconfig 查询，接收约 3 秒，保存原始字节和文本；不会设置 IP、Wi-Fi 密码或继电器。

抓取一小段采集报文

/usr/bin/python3 device_probe.py --host 192.168.1.2 --port 8266 --ys8000 --capture

发送 # 开始接收，约 3 秒后发送 $ 停止。最多保存 256 KiB 原始数据，不解码、不猜测电压、电流或标定值。程序会自动退出，若需中途停止按 Control + C。

看到收到若干字节，只能说明采集有响应。还需要根据完整协议验证帧结构、采样率与标定；空载电流很小也不能单独判断采集故障。

05

切回校园网，把结果带回来

  1. 回到「系统设置 → Wi-Fi」，连接之前使用的校园网络。
  2. 确认网页恢复联网后，把终端结果截图和「读取结果」中的 JSON/二进制文件发来。
  3. 配置回复可能包含网络信息；发送前检查文本或截图是否带 Wi-Fi 密码、访问密钥等秘密。

根据这些结果再确认设备协议，之后才进入电压/电流解析和本地 n8n 接入。网络连接、收到报文、有效测量是三个分别验证的步骤。
