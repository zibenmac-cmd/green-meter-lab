## 离线操作顺序

### 第一步：先确认 TCP 连接

- 给插座通电；由你手动将 Mac 连接到插座实际热点。软件在没有互联网时仍能运行。
- 打开项目目录这份新版：`/Users/ahaoxiao/Documents/Codex/2026-10-05/new-chat/outputs/绿电实验室Mac版/绿电实验室.app`。
- 检查连接方式为“电脑主动连接设备”，地址为 `192.168.1.1`，端口为 `8266`。这些值仍以设备实际配置为准。
- 点击“连接设备”，检查通信日志是否出现“TCP 已连接”。若仍然超时，先查热点、设备地址和端口；此时调整采样率或波形系数没有作用。

### 第二步：确认设备是否返回字节

- 若提供方确认设备使用 YS8000 手册协议：先断开，点击“YS8000 热点模板”，核对 `192.168.1.1:8266` 后重连。使用“查询配置”发送手册中的只读 `ifconfig`；然后使用“抓包 3 秒”接收原始报文。
- YS8000 短时抓包发送 `#` 并在 3 秒后发送 `$`，这与手册的开始/停止采集命令对应；无需先填写波形帧标记。
- 若提供方确认设备使用原 C# iSocket 协议，则按其真实通信角色、注册 MAC 和主动推送要求配置，不能将 YS8000 的命令混用到该模式。
- 只有收到字节后，才进入报文解析排查。

### 第三步：保存原始报文并核对解析

- 接收字节增加、有效帧数为 0：说明收到了内容，但当前帧格式没有解析成功。保存“原始 BIN”和“诊断 JSON”，恢复正常网络后提供这两个文件。
- YS8000 模式在未核对帧头、帧尾、点数、字节序前，会阻止“开始采集”的连续解析。先使用上面的短时抓包，不猜造帧标记。
- 有效帧数增加并出现合理波形后，再用参考电表核对采样率与电压、电流系数。

## 三个读数的含义

| 显示 | 所处阶段 | 下一步 |
| --- | --- | --- |
| 未连接 / 连接超时，接收字节 0 | TCP 未建立 | 先查热点与设备地址、端口 |
| TCP 已连接，接收字节 0 | 已建立连接，尚无设备回复 | 核对设备是否需要查询、启动采集命令 |
| 接收字节大于 0，有效帧数 0 | 收到内容，尚未解析为有效测量帧 | 导出原始报文，核对协议 |
| 有效帧增加、有波形 | 已解析测量数据 | 再做实测标定与稳定性验证 |

6400 Hz 当前只是软件配置值，不会自动修改设备采样率。此前模拟测试验证的是程序对已知报文的处理，尚未完成实物端到端验证。
