- 电压、电流、功率标定和软件积分电量与参考电表的一致性。
- 真实电器、不同档位及多负载组合的识别准确率。

- 生产数据写入与断连恢复的实物联调；接收接口的验证、去重与存储此前仅在空的本机测试数据库中验证。
