# Mac 版验证记录

日期：2026-10-17。环境：当前 Apple Silicon Mac，macOS 27.0.1。

本次地址更新：默认连接方式改为 TCP 客户端，目标 `192.168.1.1:8266`；保留手动连接与可选协议。此前的原上位机监听模板仍为 TCP 9876。地址修改后重新编译并复查界面，未主动连接实物地址或切换 Wi-Fi。

## 已验证

| 检查 | 结果 |
| --- | --- |
| 独立 .app 启动、本地界面、离线演示 | 通过；实际打开并操作 |
