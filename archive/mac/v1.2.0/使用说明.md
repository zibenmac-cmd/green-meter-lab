# 绿电实验室 Mac 1.2 · 自动保存与重连

## 直接开始

1. 打开本目录的 **绿电实验室.app**，确认标题为 **绿电实验室 1.2 · 自动保存与重连**。
2. 由你手动连接插座 Wi-Fi；软件不切换网络。
3. 保留 **本次插座 · 实测格式 / 192.168.1.2 / TCP 8266**。尚未做仪表对照时，不勾选标定确认。
4. 可填写“本次电器 / 状态标注”，例如“插座空载”“台灯开启”。这是人工记录，不是模型识别结果。
5. 点击 **连接插座**，观察接收字节和有效帧是否增长。
6. 结束时点 **断开 / 关闭监听**。完整原始数据已经自动保存，无需再依赖手动导出。

当前实测配置只接收设备主动发送的数据，不发送 #、$、查询或继电器指令。原上位机模板和 YS8000 模板是不同协议，不应用来替代本次插座配置。

## 自动保存在哪里

本机目录：`~/Documents/Codex/绿电实验室采集数据/真实采集/日期/会话编号/`。

界面 **打开本地记录** 可以直接进入。原始字节先落盘，约每秒执行一次文件同步。每 60 秒或每段达到 1 MiB 后封存文件；最后不足一段的记录在停止或正常退出时封存。应用没有自动删除本地原件。

| 文件 | 内容 |
| --- | --- |
| `session.json` | 会话来源、采样率配置、标定参数、开始结束时间；不含 Webhook 地址 |
| `000001-raw.bin` 等 | 收到的完整原始字节流，包含不能组成完整帧的内容 |
| `000001-summary.jsonl` 等 | 按秒统计的 ADC 或物理量摘要 |
| `000001-events.jsonl` 等 | 人工标注、会话事件 |
| `segment-000001.json` 等 | 文件大小与 SHA256，供复核副本完整性 |
| `.part` 结尾 | 尚在写入的本地文件，不向 Drive 复制 |

界面仍只缓存最近 2 MiB 供快速导出；这个限制**不影响自动保存的原始数据**。离线演示和历史文件回放不生成真实采集记录。127.x.x.x 回环联调放在 **回环测试** 文件夹，并标明非实物。

若上次未正常退出，再次打开时会保留并恢复已写入的文件，标记 `interrupted_recovered`。末尾可能是不完整帧或 JSON 行，不会补零伪造数据。磁盘不足 256 MB 时拒绝开始；写入失败会暂停采集，现有文件保留。

## Google Drive 自动同步

这台电脑已安装并登录官方 Google Drive 桌面端。应用自动识别 `ziben.mac@gmail.com` 下的 **我的云端硬盘 / 绿电实验室 / 采集数据**，也可以在界面手动选定该目录。

流程是：**本机落盘 → 分段封存 → 核对副本 → 交给 Drive 桌面端 → 云端**。应用约每 15 秒检查一次，断开和退出也尝试交接剩余文件。复制到 Drive 目录会核对 SHA256；同名但内容不同会暂停复制，避免覆盖。

连接插座热点期间没有互联网也可以采集。本地原件保留；电脑恢复互联网后，保持 Google Drive 桌面端运行，等待它完成上传。界面的“已交给 Drive 同步”表示交接完成，**云端上传进度以 Google Drive 客户端为准**。若应用在交接完成前退出，下次打开会继续检查本地待同步文件。

本轮已通过官方 Drive 连接器在云端找到同一测试会话的 5 个文件，并读回核对会话编号、来源及结束状态；测试明确标为非实物。历史两次实物抓包也已备份。目录保持私有。

## 断线处理

电脑主动连接模式下，连接超时或中断后按 1、2、4、8、16、30 秒重试，之后最多间隔 30 秒。超过 5 秒没有有效帧，状态显示非实时；已连接但连续 15 秒没有有效帧会重新建立连接。收到有效帧后重试间隔重置。

手动断开会取消自动重试。不同 TCP 连接之间不拼接残留半帧，不补算中断时段的电量。接收吞吐只是网络到达统计，不能用它单独证明设备的真实采样率。

## ADC、功率和电量

当前实测格式已经用真实抓包验证帧头、长度、16 位累加校验和尾字节。**物理通道对应、ADC 零点、比例、极性及真实采样率仍需与参考仪表核对。**

未确认标定时，只显示并保存原始 ADC 统计，W、PF、kWh 留空。约 119.4 ADC 不能当成 119.4 V。6400 Hz 是配置值，旧程序的换算系数只是参考。

只有完成上述对照后才勾选标定确认。此时软件按零点、比例和极性换算，按收到的完整帧积分。积分值覆盖已接收数据，不能当作全天连续计量。开关判断使用功率阈值和保持时间，表示近期功率活动，不独立证明完整洗衣周期结束。

“采样与标定核对”面板提供原始均值和去均值 RMS，帮助安排空载、已知负载实验；不会自动把平均值当作零点。尚没有经过真实标注数据验证的电器识别或峰谷预测模型。

## 本地 n8n（可选）

本机 n8n 2.43.8 已部署，接收流程已导入并发布，仅监听 `127.0.0.1:5678`。本轮已验证 HTTP 接收成功及错误数据拒绝。

1. 若服务未运行，双击相邻 **绿电实验室自动化** 目录中的 **启动本地n8n.command**。保持窗口运行。
2. 应用中点击 **加载配置**，选择该目录 `runtime-data/Mac本地n8n配置.json`。这是本机私有配置，不要上传分享。
3. 核对地址仍为 `192.168.1.2:8266`、标定未勾选，再连接插座。配置中的本地推送间隔为 5 秒。
4. [打开本地 n8n](http://localhost:5678)，查看“绿电实验室 · 数据接收与负载初判”。首次管理界面可能需要你本人建立本地账户和密码；接收服务已独立验证可用。

普通默认配置的 Webhook 关闭；加载本机配置后才启用。未标定时只推送 ADC 摘要，功率、电量为 null，开关状态待标定；离线回放不推送。失败会记录日志，原始文件继续自动保存，不自动补发 Webhook。n8n 不是原始文件的唯一存储。

当前流程只接收、校验和保留执行结果，不控制插座。超过 15 秒的历史摘要不作当前状态；模拟和回环数据明确标为测试。流程模板可分享，本机私有配置、n8n 数据库和登录密钥不能加入公开发布包。

## 回放与导出

**回放本次实测** 使用 2026-10-19 的 126,906 字节历史文件，应显示 242 帧、原始采集时间、两路 ADC 波形；不代表设备现在在线。**回放 BIN** 可打开自动保存的单段原始文件。

保存波形 CSV 导出最近一帧；未标定时列名标 ADC。物理量 CSV 导入、离线演示和诊断导出仍可用。原始数据可能包含设备回复，分享前检查内容。

本版在本机运行，**没有自动写入原先 chatgpt.site 网站**。Drive 备份已经接通；网站和模型的实测对接需沿用已核对的协议、单位和数据来源。
