# 绿电实验室 Mac 1.5 · 电器学习

## 第一次学习

软件首页新增“学习电器”面板。还没接上设备时可以先填写电器名称并点击“新增电器”；此时不会开始采集或给插座供电。

1. 设备准备好后，由你手动连接插座 Wi-Fi。默认目标为 192.168.1.2:8266，选择“本次插座 · 实测格式”，点击“连接插座”。供电与数据发送仍由原有按钮手动控制。
2. 接收连续波形后，选择电器和它当前的真实状态。点击“采集这一状态 · 20 秒”，保持该状态；每类至少采 3 段。
3. 第一台电器可以先采 3 段“关闭”和 3 段“运行”，再点击“学习并验证”。要区分不同电器，再加入它们的运行样本。
4. 只有采集段留出验证通过的模型才启用。收到新的实时波形后，连续 3 个窗口匹配才显示结果；差异较大或多个类别相近时显示“未知”。
5. 样本标签填错可在“查看最近的样本”中停用、恢复，再重新学习。“导出学习资料”可保存当前设备的样本、复核记录和模型。

## 判断范围

- 这是一套用你标记的样本在本机训练的轻量分类器，没有安装或冒充 GitHub 的预训练模型。
- 输入是原始 ADC 的电流幅度与波形形状、双通道相关性等 12 项特征。特征中的去均值不改变原始存档和 W 计算；频谱分箱不标为已验证的物理谐波。
- 关闭、待机只匹配活动状态，不猜电器名称；软件识别不能证明插座继电器是否接通。
- 相似电器可能无法区分。低置信或相近样本会拒绝判断，仍需用未参与采集的操作、不同日期和实际设备进一步验证。
- 验证按完整采集段划分，每折的均值、标准差和类别中心只用训练段计算；“未知”计为错误。启用门槛为平衡准确率至少 80%，它是采集段验证结果，不代表对未知电器的准确率。
- 最少 2 类、每类至少 3 段。未满 3 段的标签不进入本次模型，界面显示其进度。先按少数电器、不同状态验证，再逐步扩充。

## 数据与异常

学习只允许本次 socket128 模式下的新实时帧。历史文件、离线演示、断连、暂停、削顶和缺失窗口不能混入实时学习；中断或取消的未完成段不保存为训练数据。采集期间先完成或取消本段，再操作供电和数据指令。

每段保存人工标签、特征窗口、代表帧 ADC、原始采集会话与字节范围。学习文件是独立不可变 JSON，保存至原采集根目录的“真实采集/电器学习”；本机测试保存至“回环测试/电器学习”。按设备地址、协议和配置采样率隔离，测试模型不能用于真实设备。现有 Drive 同步会交接这些已封存文件；复制成功不代表云端已确认。

参考 W 仍未完成实物标定。软件不会因学习模型通过验证而把功率、电量或采样率标为已确认。

## 1.4 基础功能说明（历史交付原文）

# 绿电实验室 Mac 1.4 · 实时瓦数与供电控制

## 直接开始

1. 打开本目录的 **绿电实验室.app**，确认标题为 **绿电实验室 1.4 · 实时瓦数与供电控制**。
2. 由你手动连接插座 Wi-Fi；软件不切换网络。
3. 保留 **本次插座 · 实测格式 / 192.168.1.2 / TCP 8266**。尚未做仪表对照时，不勾选标定确认。
4. 可填写“本次电器 / 状态标注”，例如“插座空载”“台灯开启”。这是人工记录，不是模型识别结果。
5. 点击 **连接插座**。TCP 连接成功后，“插座供电与数据发送”里的按钮会亮起，不要求先有波形或完成标定。
6. 点击 **接通供电**，检查电器或插座指示灯；需要波形时再点 **开始发送数据 #**。若设备本来就在推送，不必重复开始。
7. 结束时按需要点击 **停止发送数据 $**、**断开供电**，最后 **断开 / 关闭监听**。停止数据和断开 TCP 都不会自动切断输出供电。完整原始数据已经自动保存，无需再依赖手动导出。

连接或重连本身不发送继电器指令；只有你点击按钮才发送。按钮按手册对应“继电器打开/关闭”，实际是否接通负载仍需你检查。原上位机模板和 YS8000 模板是不同波形协议；本次插座继续选“实测格式”，无需为使用供电按钮改换解析模板。

## 四个指令按钮

| 按钮 | 默认单字节 | 含义 |
| --- | --- | --- |
| 接通供电 | `21`（ASCII `!`） | 手册“继电器打开” |
| 断开供电 | `22`（ASCII 双引号） | 手册“继电器关闭” |
| 开始发送数据 # | `23` | 让设备发送采集数据，不代替接通供电 |
| 停止发送数据 $ | `24` | 停止设备发送数据，不代替断开供电 |

手册实际打印的是全角叹号 U+FF01 和左弯引号 U+201C，未提供线上的字节值。因此，默认单字节 21/22 只是可测试的解释，**尚未由实物验证**。展开 **供电指令格式** 可选择“手册原字符 UTF-8”：接通发送 `EF BC 81`，断开发送 `E2 80 9C`。`#/$` 在两种选择下均为 `23/24`。软件不自动轮流尝试不同编码。

每次只发送一条、不附加回车或换行，发送期间及前后 1 秒内阻止重复点击。命令和 HEX 字节保留在诊断及自动保存事件里。显示“已发送”只表示网络发送完成，不表示设备已确认执行；现有手册没有定义继电器状态回读，界面始终注明输出供电状态未核实。

离线演示、文件回放、未连接状态和旧 iSocket 模板不会启用这些按钮。重连不重放控制指令，断开不自动改变继电器。主动点击“停止发送数据”后，保留 TCP 连接供后续开关操作，暂停期间不因没有波形而触发 15 秒自动重连。

## 新增实时瓦数

首页“当前电器用电功率”显示当前 W、最近每秒记录平均和峰值。W 是有功功率单位，由同步电压、电流乘积的平均值计算，不需要先识别电器类型。不会把电压 RMS × 电流 RMS 的视在功率冒充有功功率。

未标定时会显示 **参考估算 · 未标定**，同时保留两路原始 ADC 波形；它使用当前配置中的比例、零点和极性。参考系数未核对时，数值可能有明显误差，负值不自动取绝对值。未连接、停止数据、断连或文件回放均有非实时/历史标注。

实时参考瓦数按秒自动保存到 `summary.jsonl` 的 `estimated_power_w` 字段，并带 `reference_estimate_NOT_calibrated` 和本行换算系数。`power_w` 和 `energy_kwh` 仍为 null，避免与已确认的物理计量混在一起。新增“导出参考瓦数 CSV”，并展示最近 180 条有效摘要趋势；缺失时段不补齐。

展开 **用参考仪表读数调整瓦数**，在电器稳定运行时输入另一台参考仪表实际测得的有功功率 W，可选填实际电压 V，再点“按实测读数调整参考系数”。不要用铭牌最大功率代替当前实测值。信号过小、负功率或相位异常时拒绝拟合，需先核对零点、极性和通道。

单点调整不会自动勾选正式标定。请再用另一负载复核，原始 ADC 不被改写。参考系数保存在本机采集根目录的 `reference-power-settings.json`，只在设备地址、端口及协议匹配时于下次打开恢复；文件不含 Webhook 地址。

GitHub 模型选型见同目录 **GitHub电器识别模型调研.md**。本版实现瓦数计算与参考调整，没有接入未经真实样本验证的电器类型模型。

## 自动保存在哪里

本机目录：`~/Documents/Codex/绿电实验室采集数据/真实采集/日期/会话编号/`。

界面 **打开本地记录** 可以直接进入。原始字节先落盘，约每秒执行一次文件同步。每 60 秒或每段达到 1 MiB 后封存文件；最后不足一段的记录在停止或正常退出时封存。应用没有自动删除本地原件。

| 文件 | 内容 |
| --- | --- |
| `session.json` | 会话来源、采样率配置、标定参数、开始结束时间；不含 Webhook 地址 |
| `000001-raw.bin` 等 | 收到的完整原始字节流，包含不能组成完整帧的内容 |
| `000001-summary.jsonl` 等 | 按秒统计的 ADC 或物理量摘要 |
| `000001-events.jsonl` 等 | 人工标注、会话事件 |
| `segment-000001.json` 等 | 文件大小与 SHA256，供复核副本完整性 |
| `.part` 结尾 | 尚在写入的本地文件，不向 Drive 复制 |

界面仍只缓存最近 2 MiB 供快速导出；这个限制**不影响自动保存的原始数据**。离线演示和历史文件回放不生成真实采集记录。127.x.x.x 回环联调放在 **回环测试** 文件夹，并标明非实物。

若上次未正常退出，再次打开时会保留并恢复已写入的文件，标记 `interrupted_recovered`。末尾可能是不完整帧或 JSON 行，不会补零伪造数据。磁盘不足 256 MB 时拒绝开始；写入失败会暂停采集，现有文件保留。

## Google Drive 自动同步

这台电脑已安装并登录官方 Google Drive 桌面端。应用自动识别 `ziben.mac@gmail.com` 下的 **我的云端硬盘 / 绿电实验室 / 采集数据**，也可以在界面手动选定该目录。

流程是：**本机落盘 → 分段封存 → 核对副本 → 交给 Drive 桌面端 → 云端**。应用约每 15 秒检查一次，断开和退出也尝试交接剩余文件。复制到 Drive 目录会核对 SHA256；同名但内容不同会暂停复制，避免覆盖。

## 断线处理

电脑主动连接模式下，连接超时或中断后按 1、2、4、8、16、30 秒重试，之后最多间隔 30 秒。超过 5 秒没有有效帧，状态显示非实时；已连接但连续 15 秒没有有效帧会重新建立连接。收到有效帧后重试间隔重置。

手动断开会取消自动重试；主动停止数据发送期间暂停无波形重连。不同 TCP 连接之间不拼接残留半帧，不补算中断时段的电量。接收吞吐只是网络到达统计，不能用它单独证明设备的真实采样率。

## ADC、功率和电量

当前实测格式已经用真实抓包验证帧头、长度、16 位累加校验和尾字节。**物理通道对应、ADC 零点、比例、极性及真实采样率仍需与参考仪表核对。**

未确认标定时保留原始 ADC，并新增明确标注的参考 W 估算；PF 和正式 kWh 继续留空。约 119.4 ADC 不能当成 119.4 V。6400 Hz 是配置值，旧程序的换算系数只是参考。

只有完成上述对照后才勾选标定确认。此时软件按零点、比例和极性换算，按收到的完整帧积分。积分值覆盖已接收数据，不能当作全天连续计量。开关判断使用功率阈值和保持时间，表示近期功率活动，不独立证明完整洗衣周期结束。

“采样与标定核对”面板提供原始均值和去均值 RMS，帮助安排空载、已知负载实验；不会自动把平均值当作零点。尚没有经过真实标注数据验证的电器识别或峰谷预测模型。

## 本地 n8n（可选）

本机 n8n 2.43.8 已部署，接收流程已导入并发布，仅监听 `127.0.0.1:5678`。本轮已验证 HTTP 接收成功及错误数据拒绝。

1. 若服务未运行，双击相邻 **绿电实验室自动化** 目录中的 **启动本地n8n.command**。保持窗口运行。
2. 应用中点击 **加载配置**，选择该目录 `runtime-data/Mac本地n8n配置.json`。这是本机私有配置，不要上传分享。
3. 核对地址仍为 `192.168.1.2:8266`、标定未勾选，再连接插座。配置中的本地推送间隔为 5 秒。
4. [打开本地 n8n](http://localhost:5678)，查看“绿电实验室 · 数据接收与负载初判”。首次管理界面可能需要你本人建立本地账户和密码；接收服务已独立验证可用。

普通默认配置的 Webhook 关闭；加载本机配置后才启用。未标定时推送 ADC 和独立的 estimated_power_w 字段，正式 power_w、电量为 null，开关状态待标定；现有 n8n 接收器不把估算字段提升为正式计量。离线回放不推送。失败会记录日志，原始文件继续自动保存，不自动补发 Webhook。n8n 不是原始文件的唯一存储。

当前流程只接收、校验和保留执行结果，不控制插座。超过 15 秒的历史摘要不作当前状态；模拟和回环数据明确标为测试。流程模板可分享，本机私有配置、n8n 数据库和登录密钥不能加入公开发布包。
