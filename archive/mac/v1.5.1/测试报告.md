# 绿电实验室 Mac 1.5.1 · 采集入口修复验证

日期：2026-10-26。

## 本次修复

采集按钮在无实时数据时仍可点击，显示具体原因和连接入口；采集中锁定，避免重复开始。原生采集仍强制检查实时、连接、新帧和本地保存条件。名称已存在时不再提示“先新增名称”。新增连接超时原因提示，不自动切换网络或给设备供电。

## 已完成验证

- JS 全脚本语法检查通过；界面回归覆盖：未连接、连接中、TCP 已连接但无波形、实时可采集、采集中、波形过期及空电器目录。无实时数据的点击不会发送 learningStart；用户点击连接仅提交连接请求，不发送供电指令。
- 本机 TCP 模拟源端到端：原生采集保存 21 个窗口，约 20.98 秒；按段训练、实时匹配、关闭时隐藏名称、未知拒识、断连取消、禁止回放学习及重启恢复通过。服务收到控制指令为 0 字节。详见 Evidence/1.5.1-采集按钮与学习验证.json。
- 在实际打开的 1.5.1 窗口点击采集按钮，看到“尚未连接插座”的明确提示，按钮可操作；原有“吹风机”名称保留，真实样本仍为空。
- 原生通用二进制构建与本地签名校验通过；当前 Mac 打开成功。Intel 未进行实机验证。
