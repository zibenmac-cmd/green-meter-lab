波形格式与标定参数

负载开关判断

负载状态表示近期功率活动，不能独立证明整轮洗衣结束。未确认标定时，不累计软件电量或输出已验证的开关结论。

本地 n8n Webhook（可选）

默认关闭。未标定时只发送 ADC 摘要，功率、电量为空，开关状态为待标定。失败保留本地记录，不自动重发；模拟/文件回放不推送。

网络由你在 macOS Wi-Fi 设置中手动连接。供电与数据指令由你点击按钮发送。连接或重连不自动接通、断开供电；不执行设备重置或固件升级。

第一次如何绑定？
  1. 点击“打开网站”，切到“真实记录”并用管理员口令登录。
  2. 在“记录与接入”生成采集密钥；已有密钥可直接使用。重新生成会使旧密钥失效。
  3. 填入网站登记的设备编号和采集密钥，勾选开启后保存。
  4. Mac 连上插座 Wi-Fi 后，左侧以 192.168.1.2:8266 建立连接；供电仍由你手动操作设备按钮。
  5. 插座 Wi-Fi 没网时先落盘；恢复有网后保持软件运行，即可补传。实时看网页需同时具备插座连接与互联网。

只同步真实插座每秒功率摘要及 128 点波形预览，不上传完整高频 BIN。演示、文件回放和回环测试不上传。参考功率仅用于估算，标定前不生成正式计量电量。
