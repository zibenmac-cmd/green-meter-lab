# 绿电实验室 Mac 1.6 · 网站同步

把原有 Mac 采集软件作为网站的采集端，不再另装 Python 采集器。打开本目录的「绿电实验室.app」即可。

## 第一次绑定

1. 打开 [绿电实验室网站](https://green-meter-lab-v2.ziben-mac.workers.dev/)，切到「真实记录」，使用管理员口令登录。
2. 在「记录与接入」生成采集密钥。已有密钥可直接使用；重新生成会使此前所有采集端的旧密钥失效。此处需要 **gml_ 开头的采集密钥**，不是管理员口令。
3. 打开 Mac 软件，点击顶部「网站同步」。填入网站中登记的设备编号（例如 meter-01）和采集密钥，勾选「开启真实采集自动上传和断网补传」，点击「保存同步设置」。密钥保存在 Mac 钥匙串；留空保存会保留对应设备已有密钥。
4. 插座通电后，手动将 Mac 连接到插座 Wi-Fi。在左侧选择「本次插座 · 实测格式」，使用 TCP 主动连接 **192.168.1.2:8266**。
5. 收到有效波形后，软件独立保存本地原始数据，并约每秒生成一条待传摘要；在线时每批最多上传 10 条。供电仍通过原有手动按钮操作，网站同步不会自动发送供电或采集控制指令。
6. 保持 Mac 软件运行，可最小化。网站显示最后收到数据的时间；旧数据补传不会假装设备当前在线。退出软件、关机或睡眠时不采集，也不在后台补算电量。重开软件恢复待传队列；设备连接需要重新建立。

## 网络怎么接

- **先验证读取与补传**：Mac 连接插座热点进行采集 → 暂停/断开采集 → 切回有网 Wi-Fi → 保持软件打开，自动补传。
- **需要实时查看网页**：Mac 同时保留插座 Wi-Fi 和互联网，例如 Wi-Fi 连接插座、网线连接互联网。插座能否加入实验室路由器，需先核对厂家配置方式，不能仅凭本软件保证。
- 插座 Wi-Fi 本身无互联网时，只有该条连接的 Mac 无法实时上传到 Cloudflare。软件不会自动切换你的 Wi-Fi。

## 数据范围与状态

- 上传内容：参考有功功率 W、Mac 接收时间、设备编号、连续会话编号、12 维识别特征与 128 对原始 ADC 波形预览。完整高频原始 BIN 仍保存在本机，沿用原 Google Drive 自动备份。
- 演示、离线回放、127.x.x.x 回环测试不进入真实网站队列。负功率不取绝对值冒充耗电；无效窗口不上传。
- 目前系数未经实物标定，上传记录为 **reference**，累计计量电量为空。网页按有效观测的功率计算估算用电；不能用它替代正式计量。
- 断连、停止采集、波形重新定位、长时间无帧、换设备或调整参考系数会开启新的同步会话，网站不跨这些边界补算。
- 网站电器识别仍需真实标注样本和训练验证；仅启用上传不会自动学会电器。

## 出现问题时

- 「待传」增加：检查 Mac 是否有互联网；网络恢复后软件会重试，最多约每 60 秒一次，也可点「立即补传 / 重试」。
- 「密钥无效」：从网站取得当前采集密钥，在 Mac 重新保存；原待传数据保留。
- 「其他设备」：队列记录固定绑定原设备和会话。切回对应设备编号后补传，不会重标成新设备。
- 网站待传队列上限 1 GB；达到上限时停止新增网站摘要，本机原始采集仍独立保存。请尽快联网补传。无法读取的队列文件保留并显示数量。
- 网站同步队列位于本地采集根目录的 website-sync/；settings.json 不包含密钥。不要删除 .pending 文件，除非确认无需补传。
- 如 macOS 要求访问本地网络或钥匙串，请本人按实际需要授权。此版本采用本地临时签名，并非 Apple 公证发行版。

## 构建与测试

运行 `zsh build.sh` 构建 Apple Silicon / Intel 通用应用，最低 macOS 13。新增测试在 Tests/CloudIntegration，使用本机模拟 HTTP 接收端和临时密钥；不会向生产网站写测试数据。详见「测试报告.md」。
