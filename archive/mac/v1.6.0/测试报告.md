# Mac 1.6.0 网站同步验证

日期：2026-10-27。

## 完成内容

在原生 Mac 采集软件中加入网站同步设置、Mac 钥匙串密钥保存、每秒摘要与识别波形窗口、磁盘待传队列、确认回执后删除、失败重试和重开恢复。上传到既有 Cloudflare `/api/ingest`，无需另装 Python 采集器。Google Drive 原始采集备份保留。

## 验证结果

- 原协议、存储恢复、Drive 模拟备份、供电命令、参考瓦数和电器学习回归 **135 项通过**。原历史 F251D351 抓包仍解析 242 个有效帧。这些历史数据没有上传到正式网站。
- 独立本机 HTTP 模拟接收端 **58 项检查通过**：默认关闭、密钥格式、持久化与重开恢复、503 保留记录、错误回执保留、307 不跟随、401 暂停、10+2 分批确认、重复时间回执、设备编号隔离、暂停后恢复、容量限制、原生数据来源过滤，以及原生波形 → 参考瓦数 → 待传文件 → 接收端确认。
- 最终模拟接收端收到 9 次请求、14 个唯一时间记录，重定向目的地址收到 0 次请求。所有数据与测试密钥均为合成；测试只连接 127.0.0.1。
- 原采集按钮界面回归及网站同步界面脚本检查通过。同步设置不会发送供电指令；界面刷新保留正在填写的设备编号和密钥，保存成功后清空密钥输入框，状态只返回是否已配置密钥。
- 原生上传 JSON 通过现有网站的 `validateRows` 与波形 `features` 校验。数据为 reference，计量 energy_kwh 保持 null；负功率不取绝对值。
- Apple Silicon / Intel 通用二进制构建通过，交付包中的干净应用副本完成临时签名校验。当前 Mac 实际打开 1.6.0 成功，网站同步面板可显示和跳转。Intel 没有进行实机运行验证。

## 尚待现场完成

本次未连接插座、未发送供电或采样命令，未生成或轮换生产采集密钥，也未向生产网站写入测试数据。需要用户绑定当前网站采集密钥后，连接 192.168.1.2:8266 完成现场端到端验证。6400 Hz 为配置值，物理换算仍待参考仪表核对。

只有插座热点且该热点无互联网时，实时云端上传不可用；可先采集再切回有网网络补传，或让 Mac 同时连接插座 Wi-Fi 和有互联网的网线。退出、睡眠时不会采集与上传，应用不安装后台守护进程。
