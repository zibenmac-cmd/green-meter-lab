# 绿电实验室 · Mac 电表监测 1.0

## 打开软件

解压应用包，双击 **绿电实验室.app**。界面和采集程序都在应用内，不依赖 Windows、Python、浏览器联网或远程网页。最低目标版本 macOS 13，包含 Apple Silicon 与 Intel 两种架构；已在当前 Apple Silicon Mac 上实际启动测试，Intel 仅完成编译。

应用采用本机临时签名，尚未取得 Apple 开发者签名及公证。当前 Mac 已实际打开。如其他 Mac 出现系统安全拦截，请保留提示内容再处理，不需要关闭系统安全保护。

### 当前默认连接地址

按你的要求，启动后默认使用 **电脑主动连接设备 → 192.168.1.1 → TCP 8266**。由你先连接插座所在 Wi-Fi，再点击 **连接设备**；应用启动时不会自动连接。`192.1681.1` 已按标准 IPv4 写法更正为 `192.168.1.1`。

地址与端口不决定报文协议，因此保留原 C# 单相协议为初始解析选项；如果实物确认使用 YS8000 的 `#` / `$` 指令，请改选 YS8000 模板。更改地址本身不能确认设备在线或波形已可解析。

## 先做离线演示

1. 打开应用，点击右侧 **离线演示**。
2. 查看电压、电流、有功功率、功率因数、波形、V-I 轨迹及电流谐波。
3. 点击 **保存波形 CSV** 留存样本。
4. 也可点击 **导入波形 CSV**，选择 `Tests/Fixtures/模拟电表波形.csv`；或先点击 **原上位机模板**，再点击 **回放 BIN**，选择带注册头的 `Tests/Fixtures/模拟原机报文.bin`。

以上都是模拟测试数据，不能当作插座实际测量。演示和文件分析不生成设备采集摘要，不推送 n8n。

## 连接实物前需要确认

- 插座的准确型号、说明书和通信模式。
- 插座热点的名称与密码，或插座和 Mac 所在的局域网。
- 设备是主动连接电脑，还是由电脑连接设备；对应的 IP 和端口。
- 一段真实原始接收报文，以确认与所选协议完全一致。
- 每秒 6400 点是否分别对应电压、电流，以及实际采样频率和换算系数。

当前照片不能证明该插座一定使用下面任一协议。本次没有连接实物，也没有切换 Wi-Fi。

## 模式 A：原 C# 上位机协议

提供的 7z 内有完整 C# 源码。本版根据它移植核心单相监测功能，默认采用原软件的 **电脑作为 TCP 服务端，设备主动连接电脑** 的方式。

1. 由你在 macOS 设置中连接正确网络，再打开应用。如果换了网络而地址列表未更新，请保存数据、退出后重新打开。
2. 点击 **原上位机模板**。
3. 在 **本机监听地址** 选择实际网络接口的 IPv4 地址。`127.0.0.1` 仅供电脑内部测试，实物不能连接这个地址。
4. TCP 端口默认 **9876**。依据设备已有配置，将设备的数据目标设置为此 Mac 的实际 IP 与端口；本版没有修改插座网络配置的功能。
5. 原程序支持设备连接后首先发送 6 字节 MAC，默认勾选。若真实抓包确认没有这段注册头，再取消勾选。
6. 如设备使用原机发现机制，可勾选 **回应设备发现请求 · UDP 8266**；默认关闭，仅绑定所选本机地址。
7. 点击 **启动监听**，等待设备接入。仅 TCP 已连接不代表已收到测量数据；应看到有效帧数增加和波形出现。
8. 点击 **读取参数** 可发送原机的只读参数请求。原机波形依赖设备主动推送；“开始采集”不会替设备启用一个未经确认的指令。

该格式的波形帧为 `01 14`、16 位大端载荷长度、1920 字节载荷、2 字节尾部。每帧 640 对采样：电压为有符号 16 位大端整数，电流为有符号 8 位整数。接受原机固定帧尾 `55 AA` 或通过 Modbus CRC16 校验的帧。固定帧尾表示格式匹配，并不等于 CRC 已校验。参数读取请求为 `01 04 00 00 00 50 55 AA`。

默认波形系数来自源码：电压 `0.02452 / 1.41421`，电流 `0.00257 × 128 / 1.41421`。原参数寄存器使用其各自的源码系数，单独显示；累计寄存量的单位未确认，软件不会将它直接标为 kWh。

## 模式 B：YS8000 热点协议

此前提供的 YS8000 手册描述了电脑作为 TCP 客户端连接设备的方式，与原 C# 监听模式不同。

1. 点击 **YS8000 热点模板**。
2. IP 模板已按你的要求改为 `192.168.1.1`，端口 **8266**。手册原参考地址为 `192.168.1.2`，最终以实物当前配置为准。
3. 连接后 **读取参数** 发送 `ifconfig`。如设备支持手册指令，可查看返回内容。
4. 尚未确认帧格式时，先点击 **抓包 3 秒**，导出 BIN。
5. 必须核对 3 字节帧头、3 字节帧尾、每周波点数、字节序和系数后，才使用 **开始采集** 连续解析。

YS8000 模式的 `#` / `$` 分别为手册中的开始、停止命令。本版没有继电器控制。YS8000 的旧系数仅作联调参考；不能凭这个模板确认照片中的插座型号。

## 数据与计算

- **有效值**：按接收波形计算电压、电流 RMS，保留直流分量。
- **有功功率**：逐点 `v × i` 的平均值，保留负号；不以电压 RMS 乘电流 RMS 代替。
- **功率因数**：有功功率 / 视在功率；谐波按配置频率的完整周波窗口估算，显示前 15 次。
- **采样率**：6400 Hz 是可修改的配置值，尚未经实物验证。所供 C# 源码的时间标注与此存在差异，需要实测核对。
- **软件积分电量**：确认标定后，只积分实际完整接收的波形片段；断连时不补算，负功率不计入。它不等于设备累计电量，也不是全时段总用电量。
- **负载状态**：确认标定与阈值后，使用运行/待机双阈值和持续时间判断。间歇功率降低不能单独证明整轮洗衣结束。
- **中断提示**：TCP 断开即显示未连接或等待设备；连接保持但超过 5 秒无有效帧时显示数据中断。该阈值适合本机联调，与网页原先的 60 秒规则不同。

**记录暂存在内存。** 最多保留 86400 条设备采集摘要、180 秒图表、120 条日志、最近 2 MiB 原始数据。建议先断开，再导出摘要和波形后退出。未导出摘要在退出或开始新采集时会提醒。关闭应用不会自动写数据库或同步到现有网页。

CSV 波形支持 `I,V,label` 或 `Voltage,Current` 表头，电压单位 V、电流单位 A。离线文件的采样率使用面板配置。波形 CSV 导出的是最近一帧或当前文件内容，不是完整连续录波。

BIN 回放使用当前协议与注册头选项。若从连接中途抓包、或 2 MiB 缓存已滚动覆盖开头，则文件通常没有最初的 6 字节注册 MAC，应取消该选项再回放。原始 BIN 可能含设备配置回复；分享前请自行检查内容。

## 本地 n8n 接入（可选）

默认不发送数据。展开 **本地 n8n Webhook**，填写自己的接收地址并主动勾选推送。仅接受局域网 HTTP 或 HTTPS，拒绝自动跟随重定向，不关闭证书校验。没有部署或启动 n8n 的步骤包含在本应用内。

推送字段包括 `device_id`、`timestamp`、`power_w`、`voltage_rms`、`current_rms`、`sample_rate_hz`、`calibrated`、`load_state`、`session_id`、`energy_basis`。未标定时 `energy_kwh` 为 null。仅 TCP 采集生成摘要；演示与文件不推送。失败保留本机记录，不自动重发。实际 n8n 服务尚未联调。

## 本版范围

已移植核心通信、拆包粘包、波形解析、计算、显示、CSV/BIN 文件操作及配置保存。没有移植原 Windows 软件的私有数据库账号、登录、三相界面、继电器、设备重置和固件升级功能，也没有直接运行原 `.exe`。这是依据已提供源码制作的 Mac 核心监测版，非原 Windows 软件全部功能的逐项复刻。

## 给后续开发者

- `Source/`：完整新 Mac 应用源码与本地界面。
- `Tests/main.swift`：协议、计算与状态单元检查。
- `Tests/mock_device.py`：仅连接 `127.0.0.1` 的模拟电表，生成模拟样本。
- `build.sh`：在安装 Xcode Command Line Tools 的 Mac 上生成通用 `.app` 并进行本机临时签名。

在此目录执行 `zsh build.sh` 可重建应用。原 Windows 源码及其账号配置不包含在交付包内。
